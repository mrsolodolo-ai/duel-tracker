# Duel Tracker

Scouting tool for Last War: Survival's Champion Duel qualifiers. Pick your name, pick your opponent, and it predicts their next lineup and suggests your order.

- `index.html`: the whole app (one page, no build step).
- `data/reports.json`: battle reports, one fight per line. Replace this file to update the data.
- `.nojekyll`: tells GitHub Pages to serve the files as they are.

Picks are saved on each visitor's own device.
